# Time Travel: Meeting History - Interactive Persian Historical Adventure Game

## Project Overview
**Time Travel: Meeting History** is an immersive, interactive browser-based adventure game that allows players to travel through different historical periods of Iran/Persia. The game features multiple storylines, branching narratives, and a rich visual experience with RTL (right-to-left) support for Persian language.

## Key Features
- **Multiple Historical Eras**: Travel to various Persian historical periods including:
  - Achaemenid Empire (هخامنشیان)
  - Sasanian Empire (ساسانیان)
  - Safavid Dynasty (صفویه)
  - Qajar Dynasty (قاجار)
  - Pahlavi Dynasty (پهلوی)
  - Special historical moments

- **Branching Narrative**: Every choice affects the story direction with multiple possible endings
- **Visual Customization**: Multiple themes matching each historical era
- **Audio Experience**: Background music and sound effects
- **Progress Tracking**: Save/load functionality and achievement system
- **Responsive Design**: Works on both desktop and mobile devices
- **Persian Language Support**: Full RTL layout with Vazirmatn font

## Technical Details
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Layout**: RTL (Right-to-Left) for Persian language
- **Font**: Vazirmatn font for optimal Persian typography
- **Storage**: LocalStorage for game saves and settings
- **Media**: Uses Wikimedia Commons resources for historical images and sounds
